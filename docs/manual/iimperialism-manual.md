# IImperialism! Manual

## INTRODUCTION

In IImperialism!, you rule one of the Great Powers in a world inspired on Europe in the nineteenth century. You must succeed in the realms of industry, science, diplomacy, trade, and war in order to outmaneuver competing nations and become the pre-eminent Empire in the world.

## STARTING A GAME

Boot your Apple II with the IImperialism! floppy and wait for the splash screen. Press 'ESC'. Type the name of your nation and press 'RETURN' to start a new game. The game then enters the Main Screen.

## THE MAIN SCREEN

The Main Screen is the central command screen for your empire. It shows your nation name, current turn, available funds, and an advisor prompt. From here, press 'I' for Industry, 'S' for Science, 'A' for Admiralty, 'F' for the Foreign Office, or 'E' to end the turn. Press 'ESC' to open the Game Menu.

## THE GAME MENU

From the Game Menu, you can start a new game, save your current game, or load a previous game. Press 'ESC' to return to the Main Screen.
